# 🚗 TrackMate – Smart India Hackathon 2025 Winner 🏆  
### Problem Statement 25082 – NATPAC (Govt. of Kerala)
**FULLY WORKING CODE IS IN main BRANCH**





TrackMatee is a cross-platform mobile application developed for the Smart India Hackathon 2025.  
It captures complete **trip-chain data automatically** with user consent, enabling NATPAC scientists to perform large-scale transportation research and planning.

---

## ⭐ Key Features
### 📍 Automatic Trip Detection
- Background GPS tracking  
- Start/End trip detection  
- Real-time polyline tracing  
- Distance & duration calculation  

### 📌 Manual Trip Completion
Capture:
- Trip number  
- Origin & destination (lat/long)  
- Start & end time  
- Travel mode  
- Trip purpose  
- Number of companions  
- Frequency  
- Cost incurred  

### 🗺 Google Maps Integration
- Route drawing  
- Distance calculation  
- Auto-suggest directions  
- Location picker  

### 📶 Offline Mode
- Offline trip caching using local storage  
- Auto-sync when connection restores  

### 📤 API Integration
- Secure token-based authentication  
- Trip upload  
- Trip history fetch  
- Robust error handling
